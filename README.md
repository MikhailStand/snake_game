# snake_game

Игра "Змейка", которую запускает Python-сервер.
Используется язык Python а также JS, HTML, CSS.


## Запуск

```bash
python3 snake.py
```

или

```bash
python snake.py
```

После запуска открыть адрес:

```text
http://localhost:8000
```

## Управление

- Стрелки или `WASD` - движение
- Пробел - пауза
- `Enter` - начать заново после проигрыша
