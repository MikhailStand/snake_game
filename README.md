# snake_game

Простая игра "Змейка", которую запускает Python-сервер.

Игра открывается в браузере, поэтому нормально работает в GitHub Codespaces.

## Запуск

```bash
python3 snake.py
```

Если команда `python3` не работает, попробуй:

```bash
python snake.py
```

После запуска открой адрес:

```text
http://localhost:8000
```

В GitHub Codespaces открой вкладку **Ports** и нажми на forwarded port `8000`.

## Управление

- Стрелки или `WASD` - движение
- Пробел - пауза
- `Enter` - начать заново после проигрыша

## Почему через браузер?

В GitHub Codespaces обычно нет графического экрана для `tkinter`, а терминальные игры
на `curses` могут плохо ловить нажатия клавиш. Поэтому Python запускает локальный
веб-сервер, а сама игра работает в браузере.
